# Down the Hatch (working title)

A tiny miner has been swallowed by a creature. Dig the gems out of its belly, zap the bugs
before they reach the acid, and **escape out of the other end before you are digested**.

Turn-based tool-card puzzle for the browser (desktop + touch), built for the CrazyGames
Basic Launch. **Every pixel and every sound is generated by code**: there are no image or
audio files, so the whole game is ~1.5 MB (350 KB zipped).

> Status: playable prototype with one creature (*Tiny Frog*). See `docs/DESIGN.md`.

## Play / develop

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # type-check + production build into dist/
npm run sim            # balance simulation (bots play thousands of seeded games)
npm run package:crazygames   # portal build + checks + zip in releases/crazygames/
```

Handy URL parameter: `?seed=123` plays a fixed, reproducible run.

Controls: click/tap a tool card (or keys `1`-`4`), then click/tap the belt. `Space`/`Enter`
squeezes, `E` escapes, right-click or `Backspace` cancels, `M` mutes.

## Code map

| Path | What |
|---|---|
| `src/logic/` | Pure game rules (no rendering): board, tools, spawner, levels. Used by the game **and** the simulator. |
| `src/art/` | All art by code: `pixel.ts` (pixel canvas), `sprites.ts` (gems, bugs, hero, walls, acid...), `font.ts` (5x7 font). |
| `src/audio/sfx.ts` | WebAudio synthesiser for every sound effect + ambient drone. |
| `src/scenes/` | Phaser scenes: Boot (generates textures), Title, Game. |
| `scripts/sim.ts` | Balance bots. `scripts/smoke.mjs` plays a full game with real clicks in headless Chromium. |
| `scripts/package-portal.mjs` | CrazyGames build + size/path checks + zip. |
| `docs/` | Design notes and the CrazyGames playbook. |

## Builds

One code base, two targets (`src/target.ts`): `web` (default) and `crazygames`
(`VITE_TARGET=crazygames`). The portal build has no debug hooks, ads, logins, outside links or
network calls. Debug hooks (`window.__gut`) exist only in non-portal builds with
`VITE_ENABLE_DEBUG=1` and are used by `scripts/smoke.mjs`.

Smoke test: `VITE_ENABLE_DEBUG=1 npx vite build && node scripts/smoke.mjs 5`
(plays a game via real mouse clicks, reports page errors and any external requests).
