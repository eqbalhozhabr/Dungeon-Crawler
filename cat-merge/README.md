# 🐱 گربه‌های کش‌دار — پروتوتایپ v0

ترکیبی از ۲۰۴۸ و گربه‌ها: گربه‌های هم‌سطح که ترکیب بشن، به‌جای ناپدید شدن «کش میان» و جا می‌گیرن.

## اجرا

فایل `index.html` رو توی مرورگر باز کن (نیازی به نصب یا build نیست).
یا از ریشه‌ی ریپو: `npx http-server cat-merge` و بعد باز کردن آدرسش.

کنترل: کلیدهای جهت‌دار / WASD، یا کشیدن انگشت روی تخته.

## سه حالت (برای مقایسه حس بازی)

| حالت | تخته | قانون |
|---|---|---|
| کلاسیک | ۴×۴ | ۲۰۴۸ با گربه؛ ترکیب همیشه یه خونه آزاد می‌کنه. |
| کش‌اومدن | ۵×۵ | هر سطح گربه بلندتره (طول‌ها: ۱،۱،۲،۳،۴،۵). گربه‌ی جدید روی خونه‌های ترکیب‌شده و خونه‌های خالی کش میاد. جهت سوایپ تعیین می‌کنه افقی بشه یا عمودی. گربه‌ای که کل ردیف رو پر کنه «افسانه‌ای» می‌شه، امتیاز می‌گیره و ردیف آزاد می‌شه. اگه جای کش اومدن نباشه، ترکیب انجام نمی‌شه. |
| ماهی‌خور | ۵×۵ | ماهی 🐟 اسپاون می‌شه؛ گربه‌ای که بهش برسه می‌خورتش و یه خونه بلندتر می‌شه. ترکیب هم‌سطح‌ها فقط سطح (ظاهر) رو بالا می‌بره. باز هم پر کردن ردیف = افسانه‌ای. |

## جوس (حالت کش‌اومدن)

- ترکیب: توقف کوتاه، کش و فشردگی ژله‌ای گربه‌ی جدید، ذرات، امتیاز شناور، لرزش و میو (گربه‌ی بزرگ‌تر = صدای بم‌تر؛ ترکیب‌های پشت‌سرهم هر کدوم یه پله زیرتر).
- یک خونه مونده به پر شدن ردیف: گربه می‌لرزه و ردیف چشمک می‌زنه.
- افسانه‌ای: تاریک شدن تخته، فلش طلایی ردیف، گربه تا بیرون از لبه کش میاد، بارش ماهی، بنر، و پرواز گربه به کلکسیون.
- جایزه: ۵ حرکت بعدی امتیاز ترکیب‌ها دو برابره.
- صدا با WebAudio ساخته می‌شه (دکمه‌ی 🔊 برای خاموش کردن). با «کاهش حرکت» دستگاه، لرزش و ذرات خاموش می‌شن.

## ساختار

- `engine.js` — منطق بازی بدون DOM (قابل تست با Node)
- `game.js` / `style.css` / `index.html` — رابط کاربری، گربه‌ها با SVG کد کشیده می‌شن (بدون عکس)
- `test.js` — تست‌های قانون‌ها + fuzz (`node cat-merge/test.js`)

## سؤال‌های باز برای تنظیم

- بالانس: بازی تصادفی هم گاهی افسانه‌ای می‌سازه؛ احتمالاً ۵×۵ یا نرخ ماهی باید سخت‌تر بشه.
- آیا گربه‌ی بلند باید پس از ترکیب «بیشتر» کش بیاد یا فقط به اندازه‌ی جدول طول‌ها؟
- اسپاون تصادفی یا قابل پیش‌بینی (نمایش گربه‌ی بعدی)؟
